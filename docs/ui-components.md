# UI Components

Every UI element in this app is a shadcn/ui component. Do not create custom components.

## Rules

- Always use shadcn/ui components (`base-nova` style, built on Base UI) for every UI element: buttons, inputs, forms, dialogs, cards, tables, menus, badges, alerts, etc.
- Do not create custom components. No hand-written wrappers, primitives, or reusable UI pieces in `components/` outside `components/ui/`.
- If a needed element has no installed shadcn component, add it with the CLI: `npx shadcn@latest add <component>`. Check the shadcn registry before building anything yourself.
- Do not hand-edit files in `components/ui/`. They are generated by the CLI.
- Compose pages directly from shadcn components and plain semantic HTML for layout (`div`, `section`, `main`, headings, text).
- Do not use another UI library (Radix directly, MUI, Chakra, Headless UI, etc.).

## Base UI Specifics

- Use the `render` prop for polymorphism (for example `<Button render={<Link href="/dashboard" />}>`). Never use `asChild`.
- Clerk components (`SignInButton`, `UserButton`, etc.) are allowed where authentication requires them. Wrap triggers with shadcn components, for example `<SignInButton mode="modal"><Button>Sign in</Button></SignInButton>`.

## Styling

- Style with Tailwind semantic tokens (`bg-background`, `text-foreground`, `text-muted-foreground`, `border-border`). No raw colors.
- Merge classes with `cn()` from `@/lib/utils`.
- No custom CSS files, CSS modules, or inline `style` attributes.
- Icons come from `lucide-react` only. Icon-only buttons need an `aria-label`.
- Build mobile-first and support dark mode through tokens.

## Forms

- Build forms from shadcn form primitives and submit via Server Actions.
- Show field-level errors, preserve input on error, and disable submit while pending.

## Example

```tsx
import Link from "next/link";
import { Button } from "@/components/ui/button";

export default function Page() {
  return (
    <Button render={<Link href="/dashboard" />}>Go to dashboard</Button>
  );
}
```
